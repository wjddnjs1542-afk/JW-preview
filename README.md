# 복을 읽다 v2.0.0 — First Public

첫 공개용 Phase 1 버전입니다.

## 포함 기능
- 양력 생년월일 기반 사주 계산
- 출생시간 모름 지원
- 일간·십성·오행·신강/신약·통근·일부 지지 관계 분석
- 고민 자동 분류
- 시험·자격증 / 돈 / 부업 / 직장 / 연애 / 가족 / 인간관계 / 건강 맞춤 풀이
- 행동 습관·말버릇·스트레스 방식·돈 습관·관계 패턴 해석
- 사주 조합에 따라 달라지는 결정형 문장 선택
- 충분한 분량의 결과
- 명리 근거 펼쳐보기
- 결과 복사·공유
- 모바일 반응형
- 간단한 로컬 만족도 피드백

## 공개 전 주의
- 현재 음력 변환은 지원하지 않습니다.
- 대운·세운·시험일 판정은 포함되지 않았습니다.
- 합격, 투자수익, 질병, 수명 같은 결과를 단정하지 않습니다.
- 첫 공개는 지인 테스트용으로 권장합니다.
