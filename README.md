# 복을 읽다 무료 기본 사주 MVP v1.0.0

## 업로드 방법
ZIP을 푼 뒤, 아래 파일과 폴더를 GitHub 저장소 최상위에 그대로 업로드하세요.

- index.html
- styles.css
- js/
- README.md

## 주요 기능
- 양력 생년월일 직접 입력
- 출생시간 모름 지원
- 고민 자동 분류
- 재물·부업·직장·시험·연애·가족·인간관계·건강 맞춤 풀이
- 충분한 분량의 기본 사주 해석
- 명리 근거 접기/펼치기
- 결과 복사·공유
- 모바일 반응형 UI

## 주의
- 현재 음력 입력은 안정화를 위해 비활성 안내됩니다.
- 합격·투자·건강 결과를 단정하지 않습니다.
- GitHub Pages 배포 후 1~3분 기다린 뒤 Ctrl+F5로 새로고침하세요.
